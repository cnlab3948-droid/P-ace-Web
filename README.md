# P-ace-Web
P'ACE 사용성 평가 참가자 참여 현황 대시보드

구글 스프레드시트와 실시간 연동되어 참가자가 자신의 휴대폰 번호 뒷자리 4자리를 입력하면 본인의 진행 현황을 직관적으로 확인할 수 있는 웹사이트입니다.

## 주요 기능
- **본인 간편 조회**: 휴대폰 번호 뒷자리 4자리 입력 (중복 번호 대응 모달 지원)
- **개인정보 보호**: 이름 마스킹(`김*송`) 처리
- **실시간 동기화**: Google Sheets(gviz API)와 실시간 연동되어 시트 수정 시 즉각 반영
- **설문 참여 현황**: 사전 설문 2종 (구글 폼, 인지 검사) 및 1/2차 사후 설문 단계별 표시
- **4주 사용성 평가 대시보드**:
  - 참가자별 개별 시작일 기준 주차별 날짜 자동 계산
  - **1차 2주 평가** (1주차, 2주차 주 7일 도장 달성도)
  - **1주일 휴식 주간** 리프레시 안내 배너
  - **2차 2주 평가** (3주차, 4주차 주 7일 도장 달성도)
- **모바일 최적화 UI**: 모바일 환경에 최적화된 반응형 웹 디자인
